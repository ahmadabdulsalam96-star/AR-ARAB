# 🎮 لعبة الحروف العربية بالواقع المعزز (Arabic AR Gesture Game)

مشروع React + Vite متكامل للتعرف على الحركات والأصابع بواسطة الكاميرا للتعليم التفاعلي للغة العربية.

## 🚀 النشر على Netlify و GitHub بدون Terminal:
1. قم بفك الضغط عن الملفات.
2. انشئ مستودع جديد (New Repository) على GitHub.
3. قم برفع كافة الملفات والمجلدات عبر خيار "Upload files".
4. اربط حسابك بـ Netlify وقم باختيار المستودع للنشر الفوري التلقائي!
